Claude Shannon · A Mathematical Theory of Communication

第十章：有噪信道编码定理
与纠错码

噪声不会迫使可靠速率降到零。只要码率低于容量，就能把码字在高维空间中安排得足够分散，让错误概率随着分组长度增加而趋近于零。

本页目标：理解 R<C、随机编码、噪声球、码距与 Hamming (7,4) 码

先记住一句话

容量 C 不是“零错误的瞬时速度”，而是“通过足够长的编码，可以把错误率压到任意小的最高渐近速率”。

R<C ⇒ 可使 Pₑ→0　；　R>C ⇒ 不可能使疑义度低于 R−C
本章主线：冗余把合法码字拉开距离；噪声虽然会扰动码字，但只要扰动后的“噪声球”大多不重叠，接收端就能判断原来是哪一个码字。

1. 为什么“可靠”不必以“速率趋零”为代价？

最简单的抗噪办法是重复。发送一个 bit 三次：0→000，1→111；接收端做多数表决。

码率 R=信息 bit 数/发送 bit 数=1/3 bit/次
代入：一组 3 bit 只携带 1 bit 消息，所以码率为 1÷3=0.333。重复提供了距离，却牺牲了三分之二的传输位置。

若每位独立以 p=0.1 翻转，至少两位错时多数表决才失败：

Pₑ=C(3,2)p²(1−p)+p³
=3×0.1²×0.9+0.1³=0.027+0.001=0.028
效果：原始错误率从 10% 降到 2.8%，但码率仅 1/3。香农定理更强：不必让码率随着可靠性要求不断降到 0；只要 R<C，可以用更聪明的长码同时保持正码率和任意小错误率。

2. 有噪信道编码定理的两条边界

R<C存在一系列长码
使错误率任意小
R=C渐近边界
有限长度仍很困难
R>C信息涌入过快
至少留下 R−C 疑义
若 H<C，可使错误频率或疑义度 < ε
例：源产生 H=0.4 bit/次，信道容量 C=0.531 bit/次。因为 0.4<0.531，定理保证存在足够长的编码，使错误概率低于任意预先给定的 ε，例如 10⁻⁶。
若 H>C，则 H(X|Y)≥H−C
例：若源速率 H=0.70、容量 C=0.531，则任何编码都至少留下 0.70−0.531=0.169 bit/次的疑义。自然会对超出容量的部分“收费”。
不要误读：定理不承诺某个短码在 R=C 时零错误，也不说噪声消失。它说存在越来越长的码，在严格低于容量的固定速率上，让总体错误概率趋近于 0。

3. 一个噪声球就是“一组容易混淆的输出”

发送一个长码字后，典型噪声会把它变成附近许多可能输出。这些输出围绕原码字形成“噪声球”。

码字 A
及其典型噪声输出
码字 B
及其典型噪声输出
码字 C
及其典型噪声输出
每个典型输出约有 2ⁿᴴ⁽ˣ｜ʸ⁾ 个合理输入原因
公式回答什么：接收一个长度 n 的典型输出后，还有多少输入码字看起来可能造成它？条件熵 H(X|Y) 越大，候选原因数量的指数越大，噪声球越“拥挤”。
解码原则：接收端选择最可能产生当前输出的合法码字。若每个典型输出附近只有一个合法码字，就能正确恢复；若两个合法码字的噪声区域重叠，就可能误判。

4. 用 BSC p=0.1 做一次“空间够不够”计数

上一章得到二元对称信道：

h₂(0.1)≈0.4690　；　C=1−h₂(0.1)≈0.5310 bit/次
含义：长度 n 的全部二进制空间约有 2ⁿ 个点；每个码字的典型噪声区域规模约为 2⁰·⁴⁶⁹ⁿ，所以最多可安放的可区分码字数量在指数上约为 2ⁿ/2⁰·⁴⁶⁹ⁿ=2⁰·⁵³¹ⁿ。
可可靠区分的码字数 ≈ 2ⁿᶜ

取 n=100、目标码率 R=0.4：

消息数=2ⁿᴿ=2⁴⁰≈1.10×10¹²
容量允许的指数槽位≈2ⁿᶜ=2⁵³·¹≈9.65×10¹⁵
为什么有余量：2⁴⁰ 远小于 2⁵³·¹，码本可以只选用全部 100-bit 串中的极小一部分，把码字分散开，为典型噪声留出空间。

若强行取 R=0.6：

消息数=2⁶⁰≈1.15×10¹⁸ > 2⁵³·¹
结论：要放的消息比可可靠区分的指数槽位更多，噪声区域不可避免地大量重叠。这不是某种算法不够聪明，而是容量给出的根本限制。

5. 随机编码证明为什么能证明“至少存在一个好码”？

香农没有先构造某个具体好码，而是在所有随机码本上计算平均错误率。

随机生成许多码本
→
计算每个码本错误率
→
证明平均值<ε
若 (Pₑ¹+Pₑ²+⋯+Pₑᴹ)/M < ε，则至少一个 Pₑᵐ<ε
小例子：5 个码本错误率为 0.04、0.03、0.02、0.005、0.005，平均是 0.02。若所有码本都≥0.02且至少一个更大，平均不可能仍为 0.02；这里至少有两个码本低于 0.02。
存在性而非施工图：证明告诉我们好码一定藏在巨大码本集合里，却未直接提供低复杂度的寻找与解码方法。之后几十年的编码理论，主要工作正是构造 LDPC、Turbo、Polar 等可实际实现的近容量码。

6. 为什么 R<C 时错误概率会趋近零？

设容量达到分布下，输入熵为 H(X)，疑义度为 H(X|Y)，于是：

C=H(X)−H(X|Y)

随机码本的码字密度约为 2ⁿ⁽ᴿ⁻ᴴ⁽ˣ⁾⁾；一个典型输出附近约有 2ⁿᴴ⁽ˣ｜ʸ⁾ 个可能输入。相乘得到竞争码字数量的指数：

2ⁿ⁽ᴿ⁻ᴴ⁽ˣ⁾⁾×2ⁿᴴ⁽ˣ｜ʸ⁾=2ⁿ⁽ᴿ⁻ᶜ⁾
R=0.4、C=0.531：指数为 n(−0.131)。当 n=100 时约为 2⁻¹³·¹≈0.000113；当 n 继续增大，该量指数下降到 0。
R<C ⇒ R−C<0 ⇒ 2ⁿ⁽ᴿ⁻ᶜ⁾→0
第一性原理：不是噪声球变小了，而是高维空间增长更快；只要码率留出正间隙 C−R，竞争码字落入同一典型区域的概率就会指数下降。

7. 固定可靠性要求不会改变渐近容量

令 N(T,q) 表示时长 T 内，在错误概率不超过 q 的前提下最多可可靠区分的消息数。香农定理 12：

lim(T→∞) [log₂N(T,q)]/T = C　　0<q<1
例：无论把目标错误率定为 10%、1% 还是 10⁻⁶，只要固定 q 且允许 T 越来越大，最大消息数的指数增长率都趋近 C。更严格的 q 会增加所需分组长度，却不改变最终斜率。
与无噪信道统一：无噪信道直接数时长 T 的可区分信号；有噪信道则数在给定可靠性下仍能区分的码字。两者的对数除以时间，都趋向容量。

8. 冗余必须针对噪声结构来设计

随机独立翻转需要分散码字
对抗多位置随机错
突发错误需要交织或突发码
把连续错打散
擦除信道位置已知、值未知
校验设计可更高效
码率 R=k/n　；冗余比例=(n−k)/n
Hamming (7,4)：每 7 个发送 bit 中有 k=4 个消息 bit、3 个校验 bit；R=4/7≈0.5714，冗余比例=3/7≈42.86%。
英语冗余的双刃剑：不压缩英语时，上下文能帮助恢复错字；但工程上通常先压缩源冗余，再添加结构明确、针对信道噪声的校验冗余，因为后者更可控、更接近容量。

9. Hamming (7,4) 码：四个消息位放在哪里？

香农原文采用位置 1、2、4 作为校验位，位置 3、5、6、7 作为消息位：

X₁校验 γ
X₂校验 β
X₃消息
X₄校验 α

α=X₄+X₅+X₆+X₇（偶校验）
β=X₂+X₃+X₆+X₇（偶校验）
γ=X₁+X₃+X₅+X₇（偶校验）
“偶校验”是什么意思：每一组中 1 的总数必须为偶数。加法只关心奇偶，相当于模 2 加法；若已有三个 1，就把对应校验位设为 1，使总数变成四个。

10. 完整编码：把消息 1011 编成 7 bit

把消息按顺序放入 X₃、X₅、X₆、X₇：

X₃=1，X₅=0，X₆=1，X₇=1
计算 X₄：X₅+X₆+X₇=0+1+1=2 已是偶数，所以 X₄=0。
计算 X₂：X₃+X₆+X₇=1+1+1=3 是奇数，所以 X₂=1，使总数变为 4。
计算 X₁：X₃+X₅+X₇=1+0+1=2 已是偶数，所以 X₁=0。

消息 1011 → 码字 0110011
核验三组：α 组 0+0+1+1=2；β 组 1+1+1+1=4；γ 组 0+1+0+1=2，全部为偶数，因此这是合法码字。

11. 完整纠错：第 5 位翻转后怎样定位？

假设码字 0110011 的第 5 位被噪声从 0 翻成 1，接收为 0110111：

0X₁
1X₂
1X₃
0X₄
1X₅ 错
1X₆
1X₇
α: 0+1+1+1=3 → 奇 → 1
β: 1+1+1+1=4 → 偶 → 0
γ: 0+1+1+1=3 → 奇 → 1
综合征 αβγ=101₂=5
解码：综合征的二进制值直接给出错误位置 5。把第 5 位翻回 0，恢复 0110011，再读取消息位置 3、5、6、7，得到原消息 1011。
为什么恰到好处：3 个校验 bit 有 2³=8 种综合征，恰好表示“无错误”加“7 个可能单错位置”。这正对应原文假设的 8 种等可能噪声结果。

12. 为什么这个 Hamming 码恰好达到原文信道容量？

香农 §17 的特殊信道每 7 bit 块要么无错，要么恰有 1 位错，8 种情况等概率。噪声不确定性为：

H(噪声块)=log₂8=3 bit/块
信道容量=(7−3)/7=4/7 bit/发送符号
逐项解释：每块有 7 个原始二进制自由度，必须花 3 bit 区分 8 种噪声状态，剩下 4 bit 可承载消息。因此容量为 4/7≈0.5714。
Hamming (7,4) 码率=4/7=容量
完美匹配：它用 3 个校验位恰好定位 8 种噪声状态，同时保留 4 个消息位；在这个特殊块噪声模型下可以完整纠错并达到容量。它不是说普通独立 BSC 上有限长度也能零错达到容量。

13. 三符号信道：可靠符号为什么应更常用？

香农 §15 考察三个输入符号：第一个永不受噪声；第二、第三以概率 p 正确，以 1−p 互相混淆。最优输入不一定均匀。

b=2^h₂(p)　；P₁=b/(b+2)　；P₂=P₃=1/(b+2)
p=0.9：h₂(0.9)=0.4690，b=2⁰·⁴⁶⁹≈1.384；因此 P₁≈1.384/3.384=0.409，P₂=P₃≈0.296。可靠的第一个符号使用得更频繁。
C=log₂[(b+2)/b]=log₂(1+2/b)
继续代入：C=log₂(1+2/1.384)≈log₂2.445≈1.290 bit/次。
p=1 ⇒ C=log₂3≈1.585　；p=0.5 ⇒ C=log₂2=1
边界：完全无噪时三个符号都能区分；p=0.5 时第二、第三完全不可区分，只剩“第一个”与“后两者这一组”两个有效选择。

14. 对称信道的容量可以直接读出来

若每个输入行的转移概率只是同一组数的排列，并且输出也对称，均匀输入达到容量：

C=log₂m−H(任一转移行)
BSC：输出符号数 m=2，任一行是 (1−p,p)，所以 C=log₂2−h₂(p)=1−h₂(p)。p=0.1 时 C≈0.5310。
为什么：均匀输入让输出熵达到最大 log₂m；已知输入后剩余的噪声熵等于每一行的熵。二者相减就是互信息最大值。

15. 实际应用：从定理到现代纠错系统

卫星与深空通信功率极低且重传昂贵，使用长块码在低信噪比下逼近容量。LDPC · Turbo
5G 与 Wi‑Fi根据信道质量选择码率和调制阶数，在吞吐量与可靠性之间自适应。链路自适应
SSD 与内存利用综合征定位和纠正存储位翻转，Hamming SECDED 是基础思想。校验矩阵
二维码利用 Reed–Solomon 码，即使部分模块被遮挡或污损仍能恢复。符号纠错
数据中心网络前向纠错减少重传延迟，但会增加带宽和计算开销。FEC
视频直播分层冗余和擦除码应对丢包，重要帧获得更强保护。不等错误保护
DNA 存储针对插入、删除和替换噪声设计编码，而非直接套用独立翻转模型。噪声匹配
分布式存储纠删码用较小冗余抵抗节点故障，替代简单多副本。Erasure Coding
工程检查：信道错误是独立、突发、擦除还是软信息？目标是块错误率还是位错误率？码率与容量间隔多大？分组长度、延迟、功耗和译码复杂度能否接受？

16. 自测题

问题 1：三次重复码在 p=0.1 时多数表决错误率是多少？

答案：至少两位错才失败：3×0.1²×0.9+0.1³=0.028，即 2.8%。

问题 2：为什么 R=0.4 能在 C=0.531 的信道上趋近可靠？

答案：R−C<0，竞争码字数量的关键因子 2ⁿ⁽ᴿ⁻ᶜ⁾ 随 n 指数下降到 0。

问题 3：收到 Hamming 综合征 101₂ 应翻转哪一位？

答案：101₂=5，因此翻转第 5 位。

问题 4：为什么 Hamming (7,4) 的三个校验位能区分所有单错？

答案：3 bit 有 8 种综合征，恰好对应无错和 7 个可能的单比特错误位置。

本章总结

  1. 重复码能降错，但不是高效逼近容量的方法。
  2. R<C 时存在错误率趋零的长码；R>C 时至少留下 R−C 的疑义。
  3. 纠错码通过拉开合法码字，使典型噪声区域尽量不重叠。
  4. BSC p=0.1 的容量约为 0.531 bit/次。
  5. 随机编码用“平均错误率很小”证明至少存在一个好码。
  6. 关键竞争因子是 2ⁿ⁽ᴿ⁻ᶜ⁾，R<C 时指数趋零。
  7. 固定可靠性要求影响所需块长，但不改变渐近容量。
  8. 冗余必须针对独立错、突发错或擦除等噪声结构设计。
  9. Hamming (7,4) 用三个校验位定位七个单错位置。
  10. 在香农特殊七位块信道中，Hamming 码以 4/7 码率完整纠错并达到容量。
最终直觉：可靠通信不是让噪声消失，而是只挑选少量、彼此遥远的序列作为合法码字。只要挑选密度低于容量允许的极限，高维空间就有足够余地把噪声造成的模糊隔开。
