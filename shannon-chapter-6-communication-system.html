Claude Shannon · A Mathematical Theory of Communication

第六章：通信系统组成

一个完整通信系统，不只是“把消息发出去”，而是从消息产生、编码、传输，到接收端重建并交付给目标。

本页目标：看懂消息从源到目的地的完整路径

先记住一条主线

信息源
产生消息
→
发射机
转换/编码
→
信道
承载信号
→
接收机
解码/重建
→

通信系统的每一部分都有不同职责：源产生内容，发射机把内容变成信号，信道负责承载，接收机反向恢复，目的地使用结果。

1. 信息源

信息源是消息的起点。消息可以是：

  • 离散字符序列：电报、文本；
  • 时间函数：语音、广播音频；
  • 空间和时间函数：黑白电视画面；
  • 多个时间函数：立体声音频；
  • 多个变量的组合：彩色电视、视频加音频。

2. 发射机

发射机把消息转换成适合信道传输的信号。

电话声音压力 → 电流
电报字母 → 点/划/空格
FM 广播音频 → 调制载波
发射机不一定只是“编码器”，它可能还包括采样、压缩、量化、调制等步骤。

3. 信道

信道是承载信号从发射机到接收机的媒介。

有线双绞线、同轴电缆
无线射频频段、无线频谱
光通信光纤中的光束
注意：信道不是消息本身，而是消息所经过的物理或抽象传输路径。

4. 接收机

接收机执行与发射机相反的操作，尽可能重建原始消息。

  • 电报：点/划 → 字母；
  • FM：解调载波 → 音频；
  • PCM：解码、展开、重建语音。

5. 目的地

目的地是最终使用消息的对象。

  • 电话或广播中的人；
  • 电视中的观众；
  • 数据传输中的计算机；
  • 保存信号的记录设备。

6. 三个具体例子

电话

人声 → 麦克风 → 电信网络 → 扬声器 → 听者

电报

字母 → 点划编码 → 电缆/无线 → 解码 → 收件人

FM 广播

音频 → 调频载波 → 无线电波 → 解调 → 听众

7. 为什么要分成这些组件？

  1. 便于明确每一步的功能；
  2. 可以单独优化编码、信道或解码；
  3. 可以分析时间、容量和噪声限制；
  4. 同一个信息源可以通过不同发射机和信道到达不同目的地。
香农的抽象价值在于：不管传的是文字、声音还是图像，都可以先拆成“源—发射机—信道—接收机—目的地”来分析。

8. 自测题

问题 1：把字母转换为点、划和空格，属于哪个组件的工作？

答案：发射机，因为它把消息编码成适合传输的信号。

问题 2：光纤属于哪个组件？

答案：信道，它承载信号从发射机到接收机。

问题 3：接收机和发射机是什么关系？

答案：接收机通常执行发射机的逆操作，用来解码、解调并重建消息。

本章总结

  1. 信息源产生消息。
  2. 发射机把消息转换为可传输信号。
  3. 信道承载信号。
  4. 接收机重建消息。
  5. 目的地使用或保存消息。
  6. 同一个抽象框架适用于文字、语音、图像和数据。
最终直觉：通信不是“消息瞬移”，而是一条由多个转换环节组成的流水线。
