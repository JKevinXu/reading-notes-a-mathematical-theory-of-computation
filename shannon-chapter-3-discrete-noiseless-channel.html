Claude Shannon · A Mathematical Theory of Communication

第三章：离散无噪信道

当信道没有噪声时，单位时间内最多能传多少信息？答案取决于：允许发送多少种信号，以及每种信号占用多长时间。

本页目标：理解信道容量 C

先记住一句话

信道容量不是“信号有多少种”，而是“在规定时间内，合法信号序列的数量增长得有多快”。

无噪信道：接收端能准确知道发送了哪个合法信号。这里先不讨论错误，只讨论时间、符号和约束带来的容量限制。

1. 什么是离散信道？

离散信道传输来自有限集合的符号：

S₁, S₂, …, Sₙ

符号可以是：

  • 电报码中的点和划
  • 电报或电传打字机中的字符
  • 数字系统中的 bit

每个符号可能占用不同的时间。

2. 信道容量公式

令 N(T) 表示持续 T 秒的合法信号数量：

C = lim(T→∞) log₂ N(T) / T

含义是：

  • 先数出 T 秒内有多少种合法信号；
  • 取以 2 为底的对数，换算成 bit；
  • 再除以时间 T，得到 bit/秒。

3. 最简单的例子：32 个等时长符号

假设：

符号数32 种
每个符号等时长
发送速度n 个/秒
32 种选择
→
log₂32 = 5 bit
→
C = 5n bit/秒
直觉：从 32 个选项中选一个，相当于做 5 次二选一，因为 2⁵=32。

4. 符号时长不同

如果符号的时长不同，短符号可以更频繁地发送，容量不能直接用“符号种类数”计算。

设符号时长为 t₁、t₂、…、tₙ，则合法序列数量满足：

N(t) = N(t−t₁) + N(t−t₂) + … + N(t−tₙ)

因为一个长度为 t 的序列，可以按照“最后一个符号是什么”进行分类。

5. 为什么会出现指数增长？

这类递推关系的长期行为通常接近：

N(t) ≈ X₀ᵗ

代入容量公式：

C = lim log₂(X₀ᵀ)/T = log₂ X₀
关键转换：合法序列数呈指数增长；取对数后，增长率就变成线性的“每秒 bit 数”。

6. 电报例子：约束会降低容量

电报中的符号可以有不同持续时间：

  • 点：2 个时间单位
  • 划：4 个时间单位
  • 字母间隔：3 个时间单位
  • 单词间隔：6 个时间单位

如果规定“两个空格不能连续出现”，则递推式会变成：

N(t)=N(t−2)+N(t−4)+N(t−5)+N(t−7)+N(t−8)+N(t−10)

后四项来自这样的事实：空格前面必须先有点或划，不能直接接另一个空格。

点 / 划
→
仍可发点 / 划
或发空格
→
发空格后
只能发点 / 划
结论：限制越多，合法序列越少，信道容量越低。

7. 用状态表示约束

复杂约束可以用状态机表示。状态记录“为了决定下一步，过去哪些信息还重要”。

状态 1
上一个不是空格
→
状态 2
上一个是空格

状态 1 可以发送点、划或空格；状态 2 只能发送点、划。

8. 状态机的意义

  • 节点表示状态；
  • 箭头表示允许的转换；
  • 箭头标签表示符号及持续时间；
  • 走过一条路径，就得到一个合法信号序列。
状态就是“对过去的有限记忆”。它让我们可以把“哪些序列合法”变成图和矩阵来计算。

9. 状态约束下的容量

对于多个状态，可以为每个状态之间的转换建立矩阵。矩阵元素累加从状态 i 到状态 j 的所有允许符号贡献：

Σₛ W⁻ᵇ⁽ˢ⁾ⁱʲ

令 W 为相关行列式方程的最大正实根，则：

C = log₂ W
  1. 画出状态图；
  2. 列出状态之间允许的符号和时长；
  3. 建立矩阵；
  4. 令行列式为 0；
  5. 求最大的正实根 W；
  6. 计算 C=log₂W。

10. 自测题

问题 1：为什么容量公式中要对 N(T) 取对数？

答案：合法序列数量通常呈指数增长，取对数后才能得到稳定的线性增长率，也就是 bit/秒。

问题 2：如果 32 个符号等时长、每秒发送 n 个，容量是多少？

答案：每个符号携带 log₂32=5 bit，因此 C=5n bit/秒。

问题 3：为什么“不能连续发送两个空格”会降低容量？

答案：因为可发送的合法序列变少了，N(T) 变小，所以 log₂N(T)/T 也会变小。

本章总结

  1. 离散无噪信道传输有限集合中的符号。
  2. 信道容量是单位时间可传输的信息量。
  3. C=lim log₂N(T)/T。
  4. 合法序列数量的指数增长率决定容量。
  5. 符号时长不同，会改变容量。
  6. 约束减少合法序列，因此降低容量。
  7. 状态机可以表示复杂的序列约束。
最终直觉：信道容量就是“在不违反规则的前提下，这条信道每秒能区分多少种可能”。
