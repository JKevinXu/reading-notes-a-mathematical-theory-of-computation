Claude Shannon · A Mathematical Theory of Communication

第三章：离散无噪信道

当信道没有噪声时，单位时间内最多能传多少信息？答案取决于：允许发送多少种信号，以及每种信号占用多长时间。

本页目标：理解信道容量 C

先记住一句话

信道容量不是“信号有多少种”，而是“在规定时间内，合法信号序列的数量增长得有多快”。

无噪信道：接收端能准确知道发送了哪个合法信号。这里先不讨论错误，只讨论时间、符号和约束带来的容量限制。

1. 什么是离散信道？

离散信道传输来自有限集合的符号：

S₁, S₂, …, Sₙ

符号可以是：

  • 电报码中的点和划
  • 电报或电传打字机中的字符
  • 数字系统中的 bit

每个符号可能占用不同的时间。

2. 信道容量公式：一步步理解

令 N(T) 表示持续 T 个时间单位时，信道能够发送的合法序列数量：

C = lim(T→∞) log₂ N(T) / T
① 数可能性N(T)：T 时间内有多少种合法序列
② 换算成 bitlog₂N(T)：区分这些序列需要多少次二选一
③ 除以时间得到平均每个时间单位的信息量

最简单的二进制例子

假设每个时间单位可以发送一次 0 或 1，而且没有任何限制：

  • T=1：序列为 0、1，所以 N(1)=2；
  • T=2：00、01、10、11，所以 N(2)=4；
  • T=3：共有 2³=8 种，所以 N(3)=8。
N(T)=2ᵀ　→　C=log₂(2ᵀ)/T=T/T=1 bit/时间单位
为什么取对数？1024 种可能等于 2¹⁰ 种，区分其中一个需要 10 次二选一，所以它对应 10 bit。

3. 32 个等时长符号

假设每次可以从 32 个等时长符号中任选一个：

32 种选择
→
32=2⁵
→
每个符号携带 5 bit

如果每秒发送 n 个符号：

C = n × log₂32 = 5n bit/秒
代入数字：若每秒发送 100 个符号，容量就是 5×100=500 bit/秒。前提是所有符号等时长、可以任意连接且没有噪声。

4. 符号时长不同时，递推式从哪里来？

设只有两个符号：A 用 1 个时间单位，B 用 2 个时间单位。总时长为 t 的序列，最后要么是 A，要么是 B：

  • 以 A 结尾：前面还剩 t−1，因此有 N(t−1) 种；
  • 以 B 结尾：前面还剩 t−2，因此有 N(t−2) 种。
N(t)=N(t−1)+N(t−2)

取 N(0)=1（空序列），负时间对应 0 种，则：

N(1)=1，N(2)=2，N(3)=3，N(4)=5，N(5)=8 …
枚举 t=3：AAA、AB、BA，共 3 种。递推公式的本质，就是按照“最后一个符号是什么”把序列分组。

5. 指数增长与容量

刚才的斐波那契型递推长期接近：

N(t) ≈ X₀ᵗ，其中 X₀=(1+√5)/2≈1.618

代入容量公式：

C = lim log₂(X₀ᵀ)/T = lim T·log₂X₀/T = log₂X₀
C≈log₂1.618≈0.694 bit/时间单位
直觉：如果 A、B 都只占 1 单位，容量是 1 bit/单位；现在 B 占 2 单位，发送选择受到时间拖累，所以容量下降到约 0.694。

6. 电报递推式：六项分别代表什么？

符号时长为：点 2、划 4、字母空格 3、单词空格 6；并规定两个空格不能连续出现。

N(t)=N(t−2)+N(t−4)+N(t−5)+N(t−7)+N(t−8)+N(t−10)
N(t−2)最后是点
N(t−4)最后是划
N(t−5)点(2)+字母空格(3)
N(t−7)划(4)+字母空格(3)
N(t−8)点(2)+单词空格(6)
N(t−10)划(4)+单词空格(6)

空格不能接空格，所以不能简单加入 N(t−3) 和 N(t−6)；必须把空格连同它前面的点或划一起分类。

限制为什么降低容量？若 3 个位置自由发送 A/B，有 2³=8 种；若禁止 BB，只剩 AAA、AAB、ABA、BAA、BAB，共 5 种。合法序列变少，N(T) 变小，容量也变小。

7. 用状态表示约束

以“禁止 BB”为例，只需记住上一个字符是不是 B：

  • 状态 1：上一个不是 B，可发送 A 或 B；
  • 状态 2：上一个是 B，只能发送 A。
状态 1
--B→
状态 2
--A→
状态 1

状态 2 没有发送 B 的箭头，因此 BB 自动成为非法序列。

8. 状态机的意义

  • 节点表示对过去的有限记忆；
  • 箭头表示允许的下一步；
  • 标签记录符号和持续时间；
  • 一条路径对应一个合法序列。
状态不保存全部历史，只保存判断下一步是否合法所需的最少信息。

9. 状态容量公式的简单例子

一般矩阵元素会累加从状态 i 到状态 j 的所有符号贡献：

Σₛ W⁻ᵇ⁽ˢ⁾ⁱʲ　，其中 W⁻ᵇ=1/Wᵇ

时长 b 越大，1/Wᵇ 越小，表示长符号单位时间的贡献更少。先看一个只有一个状态的系统：A 时长 1，B 时长 2。

W⁻¹ + W⁻² = 1

两边乘以 W²：

W+1=W²　→　W²−W−1=0

最大正根 W≈1.618，因此：

C=log₂W≈0.694 bit/时间单位
  1. 画状态图；
  2. 列出每条箭头的符号和时长；
  3. 建立矩阵并令行列式为 0；
  4. 求最大正实根 W；
  5. 计算 C=log₂W。
同一个答案，两种视角：递推式计算合法序列数量；状态矩阵描述允许的路径。两者最终得到相同的指数增长率和容量。

10. 自测题

问题 1：为什么容量公式中要对 N(T) 取对数？

答案：合法序列数量通常呈指数增长，取对数后才能得到稳定的线性增长率，也就是 bit/秒。

问题 2：如果 32 个符号等时长、每秒发送 n 个，容量是多少？

答案：每个符号携带 log₂32=5 bit，因此 C=5n bit/秒。

问题 3：为什么“不能连续发送两个空格”会降低容量？

答案：因为可发送的合法序列变少了，N(T) 变小，所以 log₂N(T)/T 也会变小。

本章总结

  1. 离散无噪信道传输有限集合中的符号。
  2. 信道容量是单位时间可传输的信息量。
  3. C=lim log₂N(T)/T。
  4. 合法序列数量的指数增长率决定容量。
  5. 符号时长不同，会改变容量。
  6. 约束减少合法序列，因此降低容量。
  7. 状态机可以表示复杂的序列约束。
最终直觉：信道容量就是“在不违反规则的前提下，这条信道每秒能区分多少种可能”。
