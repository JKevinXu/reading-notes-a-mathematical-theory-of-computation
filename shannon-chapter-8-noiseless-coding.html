Claude Shannon · A Mathematical Theory of Communication

第八章：有限状态转导器
与无噪编码定理

编码器如何把“常见消息用短码、罕见消息用长码”，又为什么平均码率不可能低于熵？这一章把编码操作变成有限状态机器，并给出无损压缩的根本极限。

本页目标：读懂转导器、可逆性、H/C 极限、前缀码与编码效率

先记住一句话

好编码不是把每个符号压成同样短，而是让码长匹配惊讶程度：概率约为 p 的消息，应使用约 log₂(1/p) bit。

本章主线：编码器是一台带有限记忆的机器；无损要求它可逆；可逆机器不能消灭信息；因此源熵 H 与信道容量 C 的比值决定最高传输速度。

1. 什么是离散转导器？

转导器（transducer）逐个读取输入符号，根据当前输入和内部状态产生输出，并更新状态。状态只保留未来编码仍需要的有限历史。

xₙ第 n 个输入符号
sₙ读取 xₙ 时的内部状态
yₙ本次产生的输出符号或符号块
yₙ=f(xₙ,sₙ)　　sₙ₊₁=g(xₙ,sₙ)
最小例子：设状态 sₙ 记录“前一个输入 bit”，输出 yₙ=xₙ XOR sₙ，更新 sₙ₊₁=xₙ。若当前 sₙ=0、输入 xₙ=1，则 yₙ=1 XOR 0=1，新状态变为 1。两个函数分别回答“输出什么”和“接下来记住什么”。
输入 xₙ + 状态 sₙ
→ f →
输出 yₙ
　同时 g →
新状态 sₙ₊₁

2. 逐步运行一台有限状态编码器

沿用 XOR 差分编码器，初始状态 s₁=0，输入序列为 1、1、0、1：

步骤 n当前状态 sₙ输入 xₙ输出 yₙ=xₙ XOR sₙ新状态 sₙ₊₁=xₙ
10111
21101
31010
40111
输入 1101　→　输出 1011
逐步检查：第一位与初始 0 不同，输出 1；第二位与上一输入 1 相同，输出 0；第三位与上一输入不同，输出 1；第四位再次变化，输出 1。因此输出实际上在记录“这一位是否相对前一位发生变化”。

3. 非奇异、逆转导器与无损恢复

如果存在另一台转导器，可以从输出唯一恢复原输入，原编码器就是非奇异的（non-singular），第二台机器是它的逆。

xₙ=yₙ XOR sₙ　　sₙ₊₁=xₙ
解码 1011：初始 s₁=0。x₁=1 XOR 0=1；状态变 1。x₂=0 XOR 1=1；状态仍 1。x₃=1 XOR 1=0；状态变 0。x₄=1 XOR 0=1。恢复得到 1101，与原输入完全一致。
源 X
→ 编码器 T →
码流 Y
→ 逆机器 T⁻¹ →
恢复 X
关键区别：可逆不等于每个输入符号立刻对应一个固定输出。编码器可以使用状态和变长符号块，只要完整输出最终能唯一确定完整输入。

4. 为什么无损编码不能降低熵率？

香农定理 7 指出，有限状态转导器的输出熵率不会高于输入；若转导器非奇异，则输入输出的单位时间熵相等。

Ḣ输出 ≤ Ḣ输入　；可逆时 Ḣ输出 = Ḣ输入
不可逆例子：把输入 0、1 都映射成输出 0。若输入等概率，H输入=1 bit/次；输出永远为 0，H输出=0。信息消失了，也无法恢复输入。
可逆例子：把 0→01、1→10。输入每次含 1 bit；虽然每个输入变成 2 个输出 bit，但完整输出仍唯一可逆。每个“输出 bit”的熵率可能改变，而按同一时间或每个原输入符号计的信息总量没有消失。
双向夹逼：编码器给出 Ḣ输出≤Ḣ输入；逆编码器又给出 Ḣ输入≤Ḣ输出；两式同时成立，只能取等号。

5. 无噪信道基本定理：最高能传多快？

设源每个符号产生 H bit 信息，信道每秒最多承载 C bit。理想编码下，每秒最多传输的源符号数为：

最高源符号率 = C/H　（symbols/s）
完整代入：若 H=1.5 bit/符号、C=3000 bit/s，则最高速率=3000÷1.5=2000 符号/s。每秒 2000 个符号恰好产生 2000×1.5=3000 bit/s，不超过信道容量。
实际可靠速率可逼近 C/H，但不能超过 C/H
反证式检查：若试图发送 2200 符号/s，源信息率为 2200×1.5=3300 bit/s，却只有 3000 bit/s 的信道。无损、持续传输时每秒会积压 300 bit，任何编码都无法永久消除这部分信息。
单位检查：(bit/s)÷(bit/符号)=符号/s。若单位没有约掉成目标单位，通常是公式或代入方向错了。

6. 为什么长分组能逼近极限？

先用“盒子与标签”理解：源端有许多可能消息，像一批需要区分的盒子；信道能产生不同信号，像一组不同标签。只有标签数不少于盒子数，才能给每条消息安排唯一信号。

源消息需要区分的盒子
信道信号可以使用的标签
无损编码每个盒子分配唯一标签
源端盒子数 ≈ 2ᴺᴴ　　信道端标签数 ≈ 2ᵀᶜ
符号含义：N 是一组包含的源符号数，H 是每个源符号的平均信息量；T 是允许使用的信道时间，C 是每个时间单位可提供的 bit 数。因此 NH 是整组消息约需的 bit，TC 是信道整段时间能提供的 bit。

一个精确、可以直接枚举的玩具例子

假设源每次打包 2 个符号，这个二符号包只有 8 种等可能消息。区分 8 种消息需要 log₂8=3 bit，因此每个源符号平均含有：

H=3 bit÷2 符号=1.5 bit/符号
这次不是近似：8 种消息等概率，所以整个二符号包的熵严格等于 log₂8=3 bit；平均到两个源符号就是 1.5 bit/符号。

再使用容量 C=1 bit/时间单位的二进制信道。给它 T=3 个时间单位，可用标签恰好是：

000　001消息 1、2
010　011消息 3、4
100　101消息 5、6
110　111消息 7、8
信道标签数=2^(T·C)=2^(3×1)=2³=8
刚好一一对应：源有 8 个盒子，信道有 8 张不同标签，可以做“消息1→000，消息2→001，…，消息8→111”。少于 3 个时间单位时最多只有 2²=4 张标签，不够区分 8 条消息。
N/T=2/3 符号/时间单位　　C/H=1/1.5=2/3
两条路线得到同一答案：实际映射是“3 个时间单位搬运 2 个源符号”，速率为 2/3；容量公式也给出 1÷1.5=2/3。

从玩具例子推广到长序列

2ᵀᶜ ≥ 2ᴺᴴ　⇒　TC ≥ NH　⇒　N/T ≤ C/H
逐步变形：第一步要求标签数≥盒子数；两边同取 log₂ 得 TC≥NH；再除以 TH 得 N/T≤C/H。左边是实际源符号率，右边是理论上限。
严谨提醒：对一般随机源，2ᴺᴴ 和 2ᵀᶜ 是 N、T 很大时的指数级近似，不表示有限长度下恰好有这么多条。上面的 8 消息玩具模型是为了精确演示“一一贴标签”；香农定理则说明长分组时一般源也能越来越接近这种理想匹配。
无记忆源按 N 符号分组：H ≤ L̄ₙ < H+1/N
分组越长，摊薄越明显：N=4 时额外开销上界小于 1/4=0.25 bit/符号；N=100 时小于 1/100=0.01 bit/符号。代价是编码器必须等待更多符号后再整体处理。
一句话记忆：H 决定每个源符号平均需要多少“标签位”；C 决定信道每个时间单位能提供多少“标签位”；C/H 就是每个时间单位最多能搬运多少源符号。

7. 贯穿例子：四符号源的熵

香农原文使用独立源 A、B、C、D，概率分别为 1/2、1/4、1/8、1/8：

Ap=1/2
最常见
Bp=1/4
次常见
C、D各 p=1/8
最罕见
H=−Σpᵢlog₂pᵢ
公式回答什么：它计算“每次从 A/B/C/D 中抽一个符号，平均带来多少 bit 的新选择”。概率越小的符号单次越惊讶，但出现次数也越少，因此必须乘以 p 加权。
H=−[(1/2)log₂(1/2)+(1/4)log₂(1/4)+2×(1/8)log₂(1/8)]
H=(1/2)×1+(1/4)×2+2×(1/8)×3=1.75 bit/符号
逐项解释：A 的信息量是 1 bit，平均贡献 0.5；B 的信息量是 2 bit，平均贡献 0.5；C、D 各是 3 bit，各贡献 0.375。总和 0.5+0.5+0.375+0.375=1.75 bit/符号。

为什么恰好达到熵：这些概率都是 2 的负整数次幂，理想码长 lᵢ=log₂(1/pᵢ) 分别是 1、2、3、3，刚好都是整数，所以不需要取整损失。
A B C D → 0｜10｜110｜111 → 010110111
如何无分隔解码：读到 0 立即得到 A；随后读 10 得到 B；再读 110 得到 C；最后 111 得到 D。没有任何码字是另一码字的开头，因此从左到右可唯一切分。

9. 码长为什么约等于惊讶程度？

理想码长 lᵢ≈log₂(1/pᵢ)=−log₂pᵢ
逐个代入：A 的 p=1/2，l=log₂2=1；B 的 p=1/4，l=log₂4=2；C、D 的 p=1/8，l=log₂8=3。概率每减半一次，需要多 1 bit 才能区分。
2⁻ˡⁱ≈pᵢ
反向理解：长度 1 的二进制前缀占整棵码树约 1/2；长度 2 占 1/4；长度 3 占 1/8。码树空间份额与消息概率匹配时，平均长度最小。
心智模型：短码是稀缺资源，应分配给常见消息；长码留给罕见消息。固定长度码忽略概率差异，因此通常浪费。

10. 编码效率、相对熵与压缩率

四个符号若使用固定长度二进制码，每个都要 2 bit；变长码只需平均 1.75 bit。

编码效率 η=H/L̄
最优变长码：η=1.75/1.75=1，即 100%。平均码长全部用于承载源信息，没有额外整数码长浪费。
固定长度效率=1.75/2=0.875=87.5%
浪费多少：固定码每符号多用 2−1.75=0.25 bit；相对理想长度的超额为 0.25/1.75≈14.29%。注意“效率损失 12.5 个百分点”和“码长超额 14.29%”分母不同。
同字母表相对熵=H/log₂4=1.75/2=7/8
原文结论：把二进制码每两位再映射回四符号字母表，平均压缩比为 7/8=87.5%。例如 8000 个固定长度符号位置，理想平均只需相当于 7000 个位置。

87.5%

11. 源与信道为什么要“统计匹配”？

香农把编码器类比为阻抗匹配器：编码后的信道符号，应尽量呈现能使该信道达到最大熵的统计结构。

效率 = 实际信道输入熵率 / 信道容量 C
二进制信道：若输出 0、1 各占 1/2，则每个信道符号熵为 1 bit，达到二元信道上限；若 0 占 0.99、1 占 0.01，则每个信道符号熵仅约 0.0808 bit，大量可区分序列空间没有被使用。
好码要求：log₂(1/p消息)/T消息 ≈ C
同一容量下：概率 1/8 的消息惊讶度为 3 bit。若 C=1 bit/时间单位，理想持续时间 T≈3；概率 1/2 的消息惊讶度为 1 bit，理想 T≈1。于是常见消息更短，罕见消息更长。

12. H=0、模型假设与编码边界

如果源只能产生一个确定序列，它的熵为 0；理论上接收端只要运行同样的生成规则，就不需要逐符号传输。

p₁=1　⇒　H=−1×log₂1=0 bit
例：双方都知道程序会输出 000000…，发送端无需重复发送每个 0。但若接收端不知道程序、初始条件或停止时间，这些描述本身仍需要传输。H=0 的结论依赖共同已知的模型。
香农的提醒：我们可以选择忽略一部分统计知识。例如明知某个数字序列由程序确定，却仍设计能传任意十进制数字的系统；此时计算的是在所保留约束下的最大熵，而不是该特定序列的真实熵。

13. 实际应用：这一章在哪里出现？

Huffman 编码为已知符号概率构造前缀码，使平均码长接近熵。概率匹配 · 变长码
算术编码把整段消息映射到概率区间，可更细致逼近 −log₂p 的非整数码长。长分组
文件压缩先建模重复和上下文，再用熵编码把高概率事件写成更少 bit。模型 + 编码
视频与图像编码预测先去除空间与时间冗余，再对残差符号做熵编码。条件熵
协议状态机编码器和解码器必须同步维护有限状态，否则后续码流都会错位。转导器
流式传输分组越长通常压缩越好，但首包延迟、内存和错误传播范围也更大。效率–延迟
编译器与格式转换可逆变换可改变表示和长度，却不应丢失源程序的可恢复信息。非奇异映射
信道整形把源输出转换成符合物理信道约束且接近容量最大分布的符号序列。统计匹配
建模检查：码字是否可唯一解码？编码器与解码器状态是否同步？概率模型是否匹配当前数据？平均码率是否包含码表、边界和元数据开销？更长分组带来的收益是否值得延迟和内存成本？

14. 自测题

问题 1：转导器中的 f 和 g 分别做什么？

答案：f 根据当前输入与状态产生输出；g 根据当前输入与状态更新下一状态。

问题 2：若 H=2 bit/符号、C=10,000 bit/s，最高源符号率是多少？

答案：C/H=10,000/2=5,000 符号/s。

问题 3：四符号源为什么能用 0、10、110、111 无分隔解码？

答案：这是一组前缀码，没有任何完整码字是另一码字的前缀，因此从左向右读到叶节点就能唯一切分。

问题 4：为什么长分组通常更接近熵极限，却增加延迟？

答案：长分组能把整数码长取整开销摊到更多符号上，并利用典型集合；但编码器必须先等待并缓存整块数据。

本章总结

  1. 有限状态转导器由输出函数 f 和状态更新函数 g 描述。
  2. 非奇异编码存在逆机器，可以从输出唯一恢复输入。
  3. 有限状态变换不会增加熵率；可逆时输入输出单位时间熵相等。
  4. 无噪信道中最高源符号率为 C/H，任何无损编码都不能长期超过它。
  5. 长分组利用约 2ᴺᴴ 条典型消息逼近极限，但增加延迟和复杂度。
  6. 理想码长约为 −log₂p，常见消息短、罕见消息长。
  7. 原文四符号源的熵和最优平均码长都为 1.75 bit/符号。
  8. 好编码让源的统计结构与信道容量最大分布尽量匹配。
最终直觉：编码不是创造或消灭信息，而是重新包装选择：把常走的路修短、少走的路留长，使每单位信道资源尽量都承载真正的不确定性。
